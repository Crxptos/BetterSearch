# BetterSearch
Tired of finding the level you want? Trying to memorize a song ID but can't remember it? Just look no further, as BetterSearch helps you!

## How it works
This mod lets you search by the song's name, <cr>NOT</c> the ID of the song. It also works like Google Search, so basically, if you type in "Blood" in the search bar, choices will pop up (e.g. Bloodbath, Bloodlust, etc.)
